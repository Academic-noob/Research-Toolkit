## 1. 总体计算逻辑

这套脚本的目的不是简单复制文件，而是强制把 nonrad 计算链分清楚：

```text
endpoint relax
    ↓
CCD structure generation
    ↓
CCD static single-point calculations
    ↓
WSWQ overlap calculations
    ↓
PES extraction
    ↓
Wif extraction
    ↓
capture coefficient C(T)
```

对应目录：

```text
nonrad_case/
├── 01_relax/
├── 02_ccd_structures/
├── 03_static/
├── 04_wswq/
└── 05_results/
```

## 2. 默认电荷态定义

`00_setup_nonrad_case.sh` 顶部默认：

```bash
GROUND_CHARGE="charge_state_0"
EXCITED_CHARGE="charge_state_-1"
```

因此默认：

```text
ground  = charge_state_0
excited = charge_state_-1
```

这通常对应空穴俘获：

```text
charge_state_-1 + h+ -> charge_state_0
```

如果你以后计算电子俘获或其他电荷态组合，需要修改这两行。

## 1. 完整运行命令清单

```bash
cd /home/student/works/ljd/nonrad_workflow_scripts

# 0. 检查输入
cat charge_state_0/NELECT
cat charge_state_-1/NELECT

# 1. 准备 endpoint relax
bash scripts/00_setup_nonrad_case.sh relax

# 2. 手动跑 endpoint relax
cd nonrad_case/01_relax/ground
sbatch job.sh
cd ../excited
sbatch job.sh

# 3. relax 完成后回根目录
cd /home/student/works/ljd/nonrad_workflow_scripts

# 4. 生成 CCD 结构
bash scripts/00_setup_nonrad_case.sh ccd

# 5. 准备 static 输入
bash scripts/00_setup_nonrad_case.sh static

# 6. 跑 static
sbatch scripts/job_run_static.sh

# 7. 检查 static
bash scripts/05_audit_nonrad_case.sh nonrad_case

# 8. 准备 WSWQ
bash scripts/00_setup_nonrad_case.sh wswq

# 9. 跑 WSWQ
sbatch scripts/job_run_wswq.sh

# 10. 检查 WSWQ
bash scripts/05_audit_nonrad_case.sh nonrad_case

# 11. 提取 PES
python scripts/02_extract_pes.py --case-root nonrad_case --dE 1.058

# 12. 提取 Wif
python scripts/03_get_Wif_from_WSWQ.py \
  --case-root nonrad_case \
  --branch ground \
  --def-index 192 \
  --bulk-index 189 190 191 \
  --spin 1 \
  --kpoint 1
python scripts/03_get_Wif_from_WSWQ.py --def-index 192 --bulk-index 190 191 

# 13. 计算捕获系数
python scripts/04_calculate_capture.py \
  --case-root nonrad_case \
  --dQ 1.61 \
  --dE 1.058 \
  --wi 0.0395 \
  --wf 0.0345 \
  --Wif 0.33 \
  --volume 1102.28 \
  --g 1
```
